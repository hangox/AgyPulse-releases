# AgyPulse Releases

Official macOS release downloads and Sparkle auto-update feed for **AgyPulse** (a native macOS companion overlay for Antigravity).

## Download

Download the latest notarized build from [Releases](https://github.com/hangox/AgyPulse-releases/releases/latest).

- **System Requirements**: macOS 14.0+ (Apple Silicon; macOS 26/27 recommended for native Liquid Glass)
- **Code Signing**: Signed with Developer ID and notarized by Apple

## Auto-Update Feed (Stable)

```
https://github.com/hangox/AgyPulse-releases/releases/latest/download/appcast.xml
```
